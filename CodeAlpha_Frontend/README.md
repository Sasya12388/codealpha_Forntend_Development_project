# CodeAlpha Frontend Development Tasks

This folder contains four independent projects made with HTML, CSS and vanilla JavaScript.

## Run a project
1. Open the relevant project folder in VS Code.
2. Open `index.html` in a browser, or use the Live Server extension.
3. Test all controls and check the layout at mobile and desktop widths.

## Projects
- `CodeAlpha_ImageGallery`: category filters, responsive cards, lightbox, previous/next, Escape and arrow-key support.
- `CodeAlpha_Calculator`: arithmetic operations, percentage, clear, delete, sign toggle and keyboard support.
- `CodeAlpha_Portfolio`: responsive personal portfolio with About, Skills, Projects and Contact sections.
- `CodeAlpha_MusicPlayer`: playlist, play/pause, next/previous, progress seeking and volume control.

## Before submission
- Personalize the portfolio details, email, LinkedIn, GitHub and project links.
- Test every feature yourself and be prepared to explain the HTML structure, CSS layout and JavaScript event handlers.
- The gallery uses remote Unsplash images and therefore needs internet access.
- The music player uses sample external MP3 URLs. If unavailable, add audio files you have permission to use inside a `songs` folder and update `src` values in `CodeAlpha_MusicPlayer/script.js`.
- Create a separate GitHub repository for each task using the required `CodeAlpha_ProjectName` naming format.
- Include your own screen recording/video explanation and submit through the official form shared by CodeAlpha.
